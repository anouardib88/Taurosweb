Il progetto

Una presenza pubblica, verificabile e gestita tramite GitHub.

DIBORACULUM raccoglie lavoro software in evoluzione. Qui puoi leggere lo stato senza confondere una presentazione pubblica con un prodotto già pronto all’uso.

Perché esiste

Per rendere chiari codice, decisioni e progressi, lasciando a chi visita un percorso diretto per controllare le fonti e seguire gli aggiornamenti.

Per chi è

Per sviluppatori, tester e persone interessate a esplorare il progetto o contribuire con una segnalazione concreta.

Chi lo costruisce

Sviluppato dal proprietario del repository pubblico, @anouardib88. Il repository GitHub è il riferimento per sorgenti, documentazione e discussione pubblica.

Stato attuale

Il sito informa. Il progetto continua a svilupparsi.

Disponibile ora

Una pagina statica con collegamenti al repository, alla documentazione e alle segnalazioni. Non richiede un account e non contiene un’interfaccia di accesso.

La pagina non integra moduli, analytics o cookie propri. GitHub può trattare i dati tecnici necessari a servire il sito secondo le proprie informative.
